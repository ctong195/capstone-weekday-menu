# Weekday Menu Capstone

This repository contains the capstone product specification for a weekday lunch ordering app.

## Project Goal
Build an app that:
- Generates a random 3-dish menu every weekday.
- Prices each dish at $15.95.
- Supports Apple Pay, Google Pay, and PayPal.
- Lets patrons select pickup times in 15-minute slots from 10:30 AM to 2:30 PM.
- Limits each pickup slot to a maximum of 15 meals.

## Key Document
- Product specification: `docs/spec.md`

## Suggested Next Build Steps
1. Define backend API contracts from the spec.
2. Implement menu generation and slot-capacity logic.
3. Integrate payment providers with sandbox credentials.
4. Build a simple web UI for order placement and pickup selection.
